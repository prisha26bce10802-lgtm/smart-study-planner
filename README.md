# 📚 Smart Study Planner

## 📌 Project Overview

**Smart Study Planner** is a Python-based console application designed to help students organize their academic activities efficiently.

The application allows users to manage subjects, assignments, study sessions, deadlines, and academic progress from a single platform.

---

## ✨ Features

- Add and view subjects
- Add assignments and tasks
- Set task deadlines
- View pending and completed tasks
- Mark tasks as completed
- Create study sessions
- View study schedules
- Calculate overall progress
- Generate study reports
- Save data using JSON
- Load previously saved data
